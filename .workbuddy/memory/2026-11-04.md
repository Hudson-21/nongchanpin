## 登录验证码"总是错误"的根因（11-05 修复）
- `login.jsp:199` 原写法 `if(f1.yzm.value!=<%=code%>)`：验证码未加引号，被 JS 当数字解析。
- 以 0 开头（如 0551）→ 按八进制解析成 361，"0551"!=361 恒真 → 弹"验证码错误"；0 后跟 8/9（如 0899）→ 整个 script 语法错误，ck 未定义，校验直接失效。
- 修复：改成字符串比较 `f1.yzm.value.replace(/\s/g,"")!="<%=code%>"`。
- 遗留：验证码只在前端校验，SysuserAction.memberLogin 不校验，属于装饰性防护。
